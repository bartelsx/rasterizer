# Dual Rasterizer – Space Bike Rendering

This project features a high-performance rasterizer written in C++, designed to render a futuristic space bike scene with high frame rates.

## Features
- Dual rasterization pipeline
- Multithreaded rendering
- High FPS rendering with optimized CPU usage
- Custom 3D scene: futuristic space bike

## Technologies Used
- C++
- Multithreading
- CPU-based Rasterization

## How to Run
1. Clone the repository.
2. Open the project in your IDE and build it.
3. Run the executable to view the scene.
